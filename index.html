Panduan Setup Backend Google Sheets

Untuk menggunakan aplikasi ini secara nyata, Anda perlu mendeploy kode di bawah ini ke Google Apps Script dan menautkannya dengan Spreadsheet Anda.

Langkah Penyusunan:

  1. Buka Google Sheets Anda.
  2. Klik Ekstensi > Apps Script.
  3. Ganti kode default dengan kode backend Apps Script Anda.
  4. Klik Terapkan > Penerapan Baru, pilih jenis Aplikasi Web.
  5. Salin URL Aplikasi Web yang diberikan dan taruh di variabel GAS_WEB_APP_URL.
